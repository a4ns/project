# CIRCUIT — Two minds. One way out.

Кооперативная браузерная головоломка для двух игроков за одной клавиатурой. Один ведёт персонажа к выходу, второй переключает двери и лазеры. Пять уровней с возрастающей сложностью, таймер, рестарты и экран победы.

## Управление
| Действие | Клавиши |
| --- | --- |
| Движение игрока 1 | W A S D |
| Контуры A / B / C, игрок 2 | J / K / L |
| Старт, продолжить после паузы, новая игра после победы | Enter |
| Начать текущий уровень заново | R |

Остановитесь в безопасном месте перед переключением. Закрытие двери или включение ловушки под персонажем перезапускает уровень. Таймер сохраняется при рестарте, останавливается при потере фокуса и на экране победы. После возврата в окно нажмите Enter.

Нужна физическая клавиатура. Сетевого мультиплеера и сенсорного управления нет. Игра не проверяет наличие двух разных людей: все клавиши технически доступны одному игроку.

## Запуск
Это статический сайт без сборки, npm-зависимостей, внешних CDN, API-ключей и серверной части. Для локального запуска из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8080/index.html. Python нужен только для этого способа локальной проверки.

```sh
node --test tests/*.test.cjs
```

При интеграции CORE, LEVELS и UI-QA: 15 тестов PASS, 0 FAIL, 0 SKIP. Проверены схема уровней, безопасный старт, достижимость выхода при переключениях, отсутствие решений при 40 фиксированных конфигурациях контуров, состояние движка и неизменность снимка при отрисовке.
