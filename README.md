# Cooperative Circuit Game

Одноклавиатурная кооперативная браузерная игра для двух игроков. Один управляет персонажем, второй — дверями и ловушками.

## MVP
- 2D вид сверху, пять коротких уровней.
- WASD: перемещение; J/K/L: контуры A/B/C.
- Enter: старт; R: рестарт текущего уровня.
- Общий таймер и экран победы.
- Без аккаунтов, сетевого мультиплеера и платных API.

## Статус
Создана основа проекта и план интеграции. Игровая реализация пока не готова. Руководители LEVELS и UI-QA ещё не подтвердили участие.
